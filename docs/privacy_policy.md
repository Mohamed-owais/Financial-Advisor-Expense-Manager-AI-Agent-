# Privacy Policy

## Data We Collect
- Expense entries (store, amount, category, date)
- Receipt images (OCR processed)
- User spending patterns

## Data Storage
- Encrypted database (AES-256)
- No cloud backup (local only)
- Key stored in .env (never shared)

## User Rights
- **Delete Data:** Users can delete all expenses
- **Export Data:** Users can export their data as CSV
- **Access:** Full transparency of stored data

## Security
- All data encrypted at rest
- No third-party sharing
- HTTPS only (production)

## Data Retention
- User can delete anytime
- App deletion = automatic data removal
- No data sold or shared
